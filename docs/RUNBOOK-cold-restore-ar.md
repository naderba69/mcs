# دفتر تشغيل المشغّل — إحياء التجميد من العطب (2026-09-28)

هذا الدفتر جزء من التجميد (D53). نُشر بعد **تدريب استعادة باردة** نُفِّذ فعلياً
بنفس اليوم: مُحيت `dist/` كاملة (بما فيها منصات 3.19 الثلاث)، ومُحي البناء
التطويري، وأُسقطت بتّات التنفيذ عن أدوات الاختبار — ثم أُحيي كل شيء بهذه الخطوات
بالضبط وأثبتت البطارية. اتبعه بالترتيب عند أي عطب أو استعادة.

## 0) الحالة السليمة المرجعية

| الملف | md5 |
|---|---|
| `bin/multics-r82a-stock-x64` | `3d1f58b385a7a0eea720c3c59c3bdd29` |
| `bin/multics-r82a-stats-x64` | `f6d29d2e8585f08537b6b645d4df6666` |

نسخ `bin/` الخمس دائمة (الثنائيان + `multics-r82a-arm` و`-mipsel` و`-sh4`
من 3.19). فقدان `dist/` أو `make-x64/x64/` **لا يفقد شيئاً** — كلاهما يُبنى
من المصدر. فقدان `bin/` نفسه يستحيل بهذه الخطوات إن سلم `src/`.

## 1) تحقّق من سلامة ما تبقى (من جذر `mcs/` حصراً)

```
cd mcs
md5sum -c MANIFEST-md5
```

- المتوقع: **271 OK, 0 FAILED**.
- **فخ مسجَّل بالتدريب**: التشغيل من غير جذر `mcs/` يفشل كل المدخلات (المسارات
  نسبية). 0 OK من دليل خطأ لا تعني عطبَاً.
- المدخل الوحيد الذي لا يتحقق ذاتياً هو `MANIFEST-md5` نفسه، وحسبه الفحص.

## 2) أعد بناء الإصدارين (يمسح `x64/` عمداً في كل مرة)

```
cd mcs/make-x64
make release          # -> dist/multics-r82a-stock-x64
make release-stats    # -> dist/multics-r82a-stats-x64
```

- تطابق md5 مع جدول §0 فوق = الشيفرة المجمَّدة سليمة.
- **فخ**: كل هدف `release*` يمسح `make-x64/x64/` في نهايته — البناء التطويري
  الذي تحتاجه الاختبارات الحية يختفي بعد آخر بناء إصدار. أعد بناءه بالخطوة 3.

## 3) أعد البناء التطويري (تطلبه الاختبارات الحية)

```
cd mcs/make-x64
make                  # -> x64/multics
```

## 4) أعد بتّات التنفيذ (استعادة البيئة تُسقطها والـmake يتخطى إعادة البناء)

```
cd mcs/make-x64 && chmod +x memcheck.sh
cd ../tests && chmod +x .ncclient.bin .cachepeer.bin .sp-peer.bin .u-probe.bin soak.sh 2>/dev/null
chmod +x ../bin/* ../dist/* 2>/dev/null
```

- حرّاس `chmod` داخل أهداف الاختبار تعالج معظم الحالات تلقائياً منذ جولة 3.8b،
  لكن هذه السطر يغلق الباب كله (مثال حي بالتدريب: `stdbuf: Permission denied`
  كان يظهر كـ«الخادم مات» قبل أن يظهر سببه الحقيقي).

## 5) البطارية، بالترتيب من الأسرع

```
cd mcs/make-x64
make test                       # 38 هدف اختبار، 1391 فحصاً / 0 فشل (29 ملخص نتيجة)
./memcheck.sh                   # MEMCHECK: clean (استثناء سباقات TSan = D49)
cd ../tests
make smoke no-profile pq        # الثنائية الحية: إقلاع، رفض فارغ، قيم مقتبسة طويلة
make MCS_WING_OK=1 all           # على جهاز اختبار مخصّص فقط؛ الجولة الكاملة (~21 دقيقة)
SOAK_SECONDS=1200 make -C tests soak   # التحمّل الرسمي (~20 دقيقة): PASS
```

- **فخ**: `memcheck.sh` يمسح `x64/` — شغّله **قبل** `make` التطويري إن كنت
  ستحتاج الثنائية التطويرية بعده، أو كرّر الخطوة 3 بعده.
- **تحذير أمان:** جناح `tests` يستخدم تنظيفاً عاماً بـ`pkill -9 '^multics'`؛
  لا تشغّله إلا على جهاز اختبار/تطوير مخصّص وغير إنتاجي، مع `MCS_WING_OK=1`.
  بلا العلم يرفض `preflight` البدء (rc 2).
- **فخ**: شغّل جولة `make` واحدة في اللحظة. جولتان متوازيتان تتشاركان منافذ
  الاختبارات وملفات السجل وتنتجان إخفاقات شبحية.
- `valgrind` حزمة بيئة ولا تصمد للاستعادة: `sudo apt-get install -y valgrind`
  (متوقع 3.24.x) قبل `memcheck.sh` إن غاب.

## 6) بعد أي تعديل مستقبلي (إن فُتح التجميد بأمر صريح)

1. نفّذ التعديل بقضّة قبل/بعد، ثم `make release && make release-stats` —
   البصمتان **ستتغيّران بالضرورة**؛ سجّلهما الجديدتين في كل: مدخل
   `CHANGELOG.md`، قرار DECISIONS جديد، جدول STATUS، وتقرير المهمة.
2. `make test` + `make -C tests MCS_WING_OK=1 all` **مرتين** (على الجهاز المخصّص فقط) + `memcheck.sh` + `soak` رسمي.
3. أعد توليد `MANIFEST-md5` **آخر شيء** (نفس أمر البناء الموثَّق في رأسه)
   وتحقق منه مقابل عدد صفوف التجميد الحالي (R14: 405 صفوف)، ثم احفظ خرج الفحص خارج الملف المثبّت.
4. عدّل هذا الدفتر إن تغيّر أي أمر أو فخ.

## 7) تشغيل سريع للخادم (فحص مشغّل بلا اختبارات)

```
cd mcs/bin
chmod +x multics-r82a-stats-x64
printf 'HTTP PORT: 15500\nHTTP USER: admin\nHTTP PASS: admin\n\n[ p1 ]\nCAID: 1884\nPORT: 15001\nUSER: u1 p1\n' > /tmp/quick.cfg
./multics-r82a-stats-x64 -C /tmp/quick.cfg &
curl -s -u admin:admin -o /dev/null -w '%{http_code}\n' http://127.0.0.1:15500/   # 200
# العدّادات: telnet 127.0.0.1 ثم admin/admin ثم الأمر: dcwstats
kill %1
```

بلا قسم `[ p1 ]` يجب أن يرفض الإقلاع برسالة واضحة وexit 1 (لا SIGSEGV صامت).
