# تقرير R7 — السكين الجديدة: صفحات مكتفية ذاتياً، عربية، بجلسات بتوكن (D61، 2026-09-30)

## ما المُسلَّم

واجهة الويب أعيد تصميمها بالكامل وخفتت تبعياتها إلى **صفر**: تنسيق داخلي
مضمّن في رأس كل صفحة، بلا CDN ولا خطوط خارجية ولا طلبات ثانوية — صندوق
مقطوع عن الإنترنت والمعاينة المعزولة يريان نفس المنظر بالضبط. مع تجاوب
هاتف حقيقي، وعربية/RTL كنمط كامل، وجلسات بتوكن على الباب نفسه الذي لا
يتحرك.

## السكين (src/httpstyle.c)

- **كتاب وحيد مضمّن:** `<style>` في كل رأس صفحة — لا `link` خارجي. لوغو
  الألوان بمتغيرات CSS، قائمة علوية لاصقة، جداول نظيفة بالخطوط الشريطية
  القديمة نفسها (`.maintable`/`.infotable`/`.alt1-3`... كل الخطافات
  القديمة محفوظة فلم تنكسر أي صفحة).
- **تجاوب الهاتف:** `viewport` في كل رأس، وعند ≤760px تصير الجداول كتل
  قابلة للسحب أفقياً (`overflow-x` + `white-space:nowrap`) وتختفي عبارة
  العلامة من القائمة.
- **عربي/RTL حقيقي:** `?lang=ar` (أو كوكي `MCSLANG=ar` سنة كاملة) ينتج
  `<html dir=rtl lang=ar>`، يترجم قائمة التنقل (الرئيسية، التنقيح،
  الخيوط، الخوادم، الكاش، الباقات، نيوكامد، مجكامد، المحرر، إعادة تشغيل،
  خروج) ويقلب التخطيط. `?lang=en` يرجع فوراً. **الحدود مقصودة وموثقة:**
  القوائم والعناوين ثنائية اللغة، بيانات الجداول تبقى تقنية.
- **تغاير المشغّل محفوظ:** `FILE STYLESHEET: "ملف"` يلغي السكين كلياً
  ويخدم ملفك برابط `<link>` كالسابق (ومفتاحه **متداخل تحت FILE** — كتابته
  مجرداً تُتجاهل صامتاً: درس موثق في D61).
- رابط منتدى INFOSAT الخارجي حُذف — لا مراجع خارجية إطلاقاً حتى كمراسي.

## الجلسات بتوكن على الباب نفسه

| الخاصية | القيمة |
|---|---|
| التوكِن | 256-بت من `/dev/urandom`، يُسلَّم كوكي `MCSSESSION` بـ`HttpOnly; SameSite=Strict; Max-Age=1800` |
| المنح | فقط عند نجاح Basic فعلي — لا دوران عند كل طلب يحمل توكن صالحاً |
| الخمول / العمر المطلق | 30 دقيقة / 12 ساعة |
| الجدول | 16 خانة بالذاكرة فقط (الأقدم يُطرد؛ **إعادة التشغيل تُخرج الجميع عمداً**) |
| الربط | بعنوان المصدر |
| `/logout` | بلا اعتمادات **عمداً**: لا يستطيع إلا إبطال توكن صاحبه، ويمنح كوكي انتهاء |

**الأبواب لم تتحرك:** قائمة السماح (R3) تُغلق قبل كل شيء، والفشل الحقيقي
يمشي في الخُفاض التصاعدي إلى 401، والغريب والتوكن المزور نفس الـ401 —
كل فحوص R3 القديمة خضراء في الجناح دون تعديل.

## الآلية: ثلاث كتابات بدل 66 كتابة ثابتة

`http_replyok_write()` (تحمل كتلتي Set-Cookie)، `http_html_write()`
(تنتج وسم HTML بالاتجاه)، `http_style_write()` (تضمّن السكين أو تُبقي
الرابط عند التغاير). استُبدلت **23 موقع replyok و22 موقع html و21 موقع
style** آلياً — وقاعدة جديدة موثقة: أي صفحة جديدة تستخدمها لأن الثوابت
القديمة لا تحمل كوكي ولا اتجاهاً. جزئية AJAX (تبديل `#mainDiv` بالتحديث
التلقائي) سلوك stock أصلي وبقيت كما هي.

خارجي؛ التوكن وحده يفتح كل الصفحات؛ المزور والغريب 401؛ الخروج يُنهي

`?lang=en` يرجع؛ `/style.css` يخدم المضمّن للأدوات القديمة؛ التوكن الميت
لا يقرأ `/json`؛ وتغاير `FILE STYLESHEET` يفوز برابط.

## الأفخاخ الموثقة هذه الجولة

1. **مفاتيح الإعداد متداخلة:** `FILE STYLESHEET:` وليس `STYLESHEET:` —
   المفتاح المجرد يُتجاهل صامتاً (لا خطأ، قيمة فارغة).
2. **فحوص grep على الصفحات تُثبَّت بالوسم الحرفي:** `<HTML dir=rtl` —
   فحص `dir=rtl` المجرد يوقع في نص CSS نفسه (`html[dir=rtl]`).
3. **لوغ الخادم المقتول `-9` فارغ** إلا مع `stdbuf -o0` — التخزين المؤقت
   للملف يرمى مع العملية.
4. `head -c N` يحسب البايتات **مع** الفراغات الزائدة — مقارنة بادئة ناقصة
   بايت تُفشل ثلالث جولات قبل أن تُرى.

## الحدود

الترجمة تغطي قائمة التنقل وعناوين الواجهة وسطور الحالة — ليس كل خلية
جدول في كل صفحة (بيانات تشغيلية تقنية، وعولتها لا تخدم أحداً). الجلسات
بلا تخزين دائم: إعادة تشغيل = خروج الجميع (قرار أمني موثق). لا مفاتيح
إعداد جديدة إطلاقاً في هذه الجولة.
