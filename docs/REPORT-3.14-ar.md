# تقرير TASK 3.14 — قائمة `BAD-DCW` تعمل — 2026-09-26

## الخلاصة بالعربية الواضحة

السطر الموثّق كان يُقرأ ويُتجاهل. المفتاح الذي يكتبه المشغّل كان يصل
إلى العميل. هذا هو السبب 4 في وثيقة الشاشة السوداء.

الآن السطر يفعل ما يَعِد به:

- مفتاح مكتوب في `BAD-DCW` لا يُسلَّم للعميل.
- العدّاد `bad-dcw-list` يزيد بواحد (حين تكون `DCW STATS` مفعّلة).
- مفتاح غير مكتوب يمر، والعدّاد يبقى 0.
- بلا سطر لا يتغيّر شيء، ولا يُكتب سجل. هذا هو الوضع الافتراضي.
- إزالة السطر من الملف تمسح القائمة. السجل يقول `BAD-DCW: list cleared`.
- السقف 32 مفتاحاً. ما زاد يُذكر مرة ولا يُفرض.
- الإصدار العادي (بلا عدّادات) يرفض المفتاح المكتوب أيضاً. العدّ يظهر
  في إصدار الإحصائيات فقط.

مثال السطر كما في التوثيق:

```
BAD-DCW: FD FF FF FB FD FF FF FB FD FF FF FB FD FF FF FB
```

عند الإقلاع ومع وجود سطر واحد:

```
!!! BAD-DCW: 1 entry enforced
```

## الدليل

الخادم اشتغل، وعميل Newcamd طلب المفتاح، والنظير دفعه. الرفض حدث داخل
الخادم، لا في أداة الاختبار.

| الفحص | النتيجة |
|---|---|
| المفتاح المكتوب | لم يُسلَّم |
| صفحة الويب | `bad-dcw-list` = 1 |
| السجل | `BAD-DCW: 1 entry enforced` |
| مفتاح غير مكتوب | سُلِّم مرتين، والعدّاد بقي 0 |
| إزالة السطر | السجل: `BAD-DCW: list cleared` |
| خادم بلا سطر | المفتاح نفسه سُلِّم، ولا سطر `BAD-DCW` في السجل |
| الإصدار العادي | يرفض المفتاح المكتوب أيضاً |
| الخادم | بقي حيّاً |
