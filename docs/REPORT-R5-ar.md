# TASK R5 — نقطة القراءة الآلية: `GET /json`

**التاريخ:** 2026-09-29 · **القرار:** D59 · **الحالة:** مكتمل — أخضر بالكامل

## 0. الخلاصة في سطرين

كل أرقام أربع جولات (R1-R4) كانت حبيسة HTML وتيلنت؛ R5 فتحها للآلات بمسار
واحد `GET /json` خلف نفس باب Basic: مستند واحد به عدّادات dcwstats كلها،
وسلّم سمعة النظراء R4 بعتباته وسجلاته، وصفوف النظراء مدمجةً فيها حالة
السلم. بلا مكتبات خارجية، وبلا مفتاح إعداد جديد.

## 1. القرار الدلالي (D59)

| البند | القرار |
|---|---|
| المسار | `GET /json` داخل سلسلة gererClient **بعد** بوابة Basic — يرث بيانات الدخول نفسها وقائمة/تأخير R3 تلقائياً |
| المستند | ستة أقسام بترتيب مثبّت: `version` `uptime` `now` `dcwstats` `peerrep` `cache_peers` |
| المكتبات | لا شيء خارجي: `monjson.{c,h}` باني نقي — المستدعي يلتقط اللقطة، الباني يرسم، المستند الفائض يُهمل كله (لا JSON مقطوع يُخدَم أبداً) |
| النكهتان | الشكل واحد؛ stock يخدم `dcwstats.on=0` وصفر عدّادات — لوحة Grafana واحدة تعمل على النكهتين |
| المرحلة | رقماً (`stage`: 0-3) للتنبيهات واسمًا (`stage_name`) بنفس كلمات السلم/PEERREP/الملف |
| الثقة لكل قناة | بقيت داخلية عمداً (وسيط تنقيط لا سطح تنبيه) — المواجه للمشغّل هو السلم + الصفوف |
| التهريب | RFC 8259: اقتباس/مائل/بايتات التحكم، و≥0x80 يمر خاماً (UTF-8) — أسماء النظراء بيانات لا ترميز |

## 3. الهدف الحي `jm` — الدليل التشغيلي (8/8 أخضر، ~62 ث)

1. الغريب (اعتمادات خاطئة) → **401** كسائر الصفحات.
2. المستند ينفك JSON ويحمل الأقسام الستة.
3. قسم dcwstats: كل الأسماء التسعة + `accepted` كأعداد صحيحة (بناء
   stats يُظهر فيض التسميم في `cycle-contradiction` أيضاً).
4. قسم السلم: العتبات المسلحة 3/6/10 والقائمة فارغة.
5. النظير الصادق online يظهر صفاً بـping و`rep_stage: -1`.
6. فيض تسميم حقيقي 150ms يُصعّد فعلاً (سطر اللوج يُفحص قبل قراءة المستند
   — الدليل حي لا مقروء من المنتج نفسه).
7. سجل السلم الحي في المستند (`127.0.0.1:B` مرحلة ≥1 و3+ أحداث).
8. السجل نفسه مدمج في صف النظير (`rep_stage`/`rep_events`/`rep_last`).
