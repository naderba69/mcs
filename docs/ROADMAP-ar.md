# خارطة الطريق بعد التجميد — 2026-09-28

نتيجة نقاش «تطوير المولتي ليواكب تطورات ومشاكل الشيرينغ وتحسين التصميم»
(دون كود). القرارات أدناه **مصحوبة بجواب المستخدم الصريح** في الأسئلة
الأربعة، وستُنفَّذ مهمةً واحدة لكل «واصل» وفق قيد الإيقاع الثابت.
القرار المسجّل في سجل القرارات: **D54**.

---

## إجابات المستخدم الحاسمة (2026-09-28)

1. **معنى «تحسين الديزاين»: الاثنان معاً** — نبدأ بالتصميم الداخلي ثم
   نكسو الواجهة.
2. **أول بند عند أول «واصل»: تحصينات cacheex الحديثة** — نظائر
   `BLOCK_FAKE_CW` و`LOCAL_ONLY` و`CWCHECK` و`MAXHOP_LG` بطبقتنا
   وبعد التحقق، لا الدمج الأعمى.
3. **التغييرات البنيوية مقبولة شرط بقائها خلف راية تجميع** — والثنائي
   المتجمد (D53: `3d1f58b3…` / `f6d29d2e…`) لا يُمس مطلقاً.
4. **طبيعة الشبكة: شركاء r107/oscam حديثون** — التحصينات الجديدة تُبنى
   opt-in لكل نظير (افتراضياً مطفأة) حفاظاً على التشابك مع الأقدم.

## الحقائق الأرضية التي بُني عليها النقاش (تحقق مباشر على الشجرة)

- `cacheex.c` يحوي أوضاع 1/2/3 فعلاً، وcs378x مكتمل الاتجاهين
  (srv-cs378x.c + cli-cs378x.c)، وكذلك camd35/cccam/newcamd/mgcamd/
  radegast/freecccam.
- الكاش UDP: `recvfrom` واحد + مطابقة IP + حارس GR10 — **بلا مصافحة
  ولا كوكي ولا حد معدل لكل IP** (سطح انتحال مصدر قائم).
- HTTP/تيلنت: Basic auth بلا قفل محاولات ولا تأخير تصاعدي.
- الاكتشاف الحي أثناء ترحيل إعدادات المستخدم: **تسرّب حالة المنفذ بين
  الباقات** (`config.c:941-942` — عدّاد المنفذ لا يُصفَّر عند `[`) —
  قرار التصميم: إبقاء التوافق + سطر تحذير في اللوج عند الاعتماد على
  الميراث، لا كسر سلوك ملفات قائمة.
- والاكتشاف الأمني المرافق: بلا `HTTP PORT` يفتح r82a الويب على 5500
  **بلا كلمة مرور** (مثبت حياً: curl بلا بيانات = 200).
