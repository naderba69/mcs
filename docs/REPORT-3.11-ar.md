# تقرير TASK 3.11 — أوامر telnet `dcwstats` و`dcwstats reset` — 2026-09-26

## الخلاصة بالعربية الواضحة

بعد `DCW STATS: ON` كانت العدّادات تُجمَّع ولا أحد يقرأها. الآن من طرفية
telnet:

```
dcwstats
dcwstats: ON
accepted 0
checksum 0
null/half-null 3
repeat-3-bytes 0
bad-dcw-list 0

dcwstats reset
dcwstats: counters reset
```

- **بلا كلمة ثانية:** الحالة (ON أو OFF) ثم سطر لكل سبب، بالأسماء التي
  ستعيدها صفحة الويب في المهمة التالية حتى لا يختلف الرقمان.
- **`dcwstats reset`:** يصفّر فعلاً، حتى لو كان التجميع متوقفاً، حتى
  تُمسح بقايا قبل إعادة التشغيل.
- **كلمة ثانية غير reset:** سطر استعمال، ولا يصفّر.
- **إصدار المخزون** (بلا عدّادات): نفس الأمر يجيب مرة واحدة
  `this build has no counters; use the stats release`، ولا يدّعي أنه صفّر.
- **`help`** يذكر الأمر في الإصدارين.

## الدليل أن التصفير حقيقي

نظير كاش دفع مفتاحاً كله أصفار. مجموع التدقيق ينجح، والرفض يأتي من
اختبار المفتاح الصفري، فيتحرك عدّاد `null/half-null` وحده. قُتل النظير
قبل جلسة الإثبات حتى لا تعيد دفعة لاحقة ملء العدّاد بين التصفير والقراءة
التالية.

| الفحص | النتيجة |
|---|---|
| الرفض حرّك العدّاد | `null/half-null` غير صفر |
| القراءة تقول ON وتسمّي العدد | نعم |
| `dcwstats nope` | سطر استعمال، والعدد كما هو |
| `dcwstats reset` ثم قراءة | كل الخانات صفر |
| بلا سطر في الإعداد | `dcwstats: OFF` والعدادات صفر |
| إصدار المخزون | إجابة واحدة تسمّي الإصدار المطلوب، و`help` يذكر الأمر |
