# تقرير TASK 3.12 — العدّادات في الصفحة الرئيسية — 2026-09-26

## الخلاصة بالعربية الواضحة

الصفحة الرئيسية (`/`) تعرض الآن عدّادات رفض المفاتيح، في الجزء الذي
تجدّده الصفحة بنفسها. الأسماء هي أسماء telnet نفسها، وكل نص يمر عبر
`html_esc` قبل وضعه في الصفحة (درس 3.2). الأرقام تُطبع كأعداد لا كنص
قادم من الخارج.

```
DCW stats ON
accepted          0
checksum          0
null/half-null    3
repeat-3-bytes    0
bad-dcw-list      0
```

- **ON / OFF** كما في telnet. بلا سطر في الإعداد: OFF والعدادات صفر،
  في الصفحة وفي telnet معاً.
- **لا زر تصفير في الويب.** التصفير يبقى أمر telnet `dcwstats reset`.
  زر في صفحة تتجدد وحدها كان سيصفّر العدّادات عند كل تحديث.
- **إصدار المخزون** يرسم الصفحة كما كانت (وقت التشغيل، المجاميع، الرابط)
  ويكتب الجملة نفسها التي يقولها telnet:
  `this build has no counters; use the stats release`. بلا جدول عدّادات،
  وبلا أي إشارة إلى الرمز.

أسماء اليوم بلا محارف خاصة، فالنص في الصفحة يطابق telnet حرفاً حرفاً.
التهريب موجود حتى لا يكسر اسم لاحق فيه `&` الصفحة.

## الدليل أن الأرقام هي نفسها

نظير كاش دفع مفتاحاً كله أصفار، فتحرّك `null/half-null`. قُتل النظير،
ثم قُرئت الصفحة وجزء التجديد وtelnet في اللحظة نفسها.

| الفحص | النتيجة |
|---|---|
| الرفض ظاهر في الصفحة | الصفحة 200 والعدّاد غير صفر |
| الصفحة لم تنكسر | وقت التشغيل والجدول و`</html>` في مكانهم |
| جزء التجديد | يحمل الجدول وليس مستنداً ثانياً |
| كل خانة | الصفحة = جزء التجديد = telnet |
| بلا سطر إعداد | الصفحة وtelnet: OFF وصفر |
| إصدار المخزون | الصفحة تُرسم، والجملة موجودة، ولا جدول |
