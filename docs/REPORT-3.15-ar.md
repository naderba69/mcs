# تقرير TASK 3.15 — `DCWFILTER` لكل بروفايل — 2026-09-26

## الخلاصة بالعربية الواضحة

البوابتان كانتا للخادم كله. إيقاف فحص المجموع لباقة واحدة كان يوقفه
لكل الباقات. الآن السطر نفسه يُكتب داخل البروفايل.

- سطر داخل البروفايل يتجاوز بوابة واحدة: `ON` يفرض التشغيل، `OFF` يفرض
  الإيقاف.
- بروفايل بلا سطر يبقى على البوابة العامّة. الافتراضي ما زال الاثنتين
  تعملان.
- باقي البروفايلات لا تتغيّر.
- المفتاح الفارغ لا يمر من أي بروفايل. المفتاح المكتوب في `BAD-DCW` لا
  يُتجاوز أيضاً.
- الإصدار العادي (بلا عدّادات) يحترم الاستثناء كذلك.

مثال:

```
DCWFILTER CHECKSUM: ON

[ pfa ]
CAID: 1884

[ pfb ]
CAID: 1884
DCWFILTER CHECKSUM: OFF
```

عند الإقلاع:

```
config(21,23): DCWFILTER CHECKSUM: OFF (profile pfb )
```
